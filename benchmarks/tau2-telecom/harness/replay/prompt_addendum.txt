Before transferring the user to a human agent: work through every section of the technical support manual that applies to the user's issue, in order; after each change you ask the user to make, ask them to re-check the symptom (for example run a speed test or try sending the message again); and check the account side (line status, bills, data usage, roaming). Transfer only when every applicable step has been tried and the problem persists, or when the manual or policy explicitly says to escalate.
